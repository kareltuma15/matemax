Přihlašovací e-maily přes Resend

Potvrzení e-mailu po registraci a zapomenuté heslo posílá Supabase. Tímhle nastavením půjdou z adresy MateMaxu přes Resend a budou vypadat jako ostatní e-maily. Dítěti píše Hexík, rodiči se vyká (Supabase to pozná sám podle toho, jestli je účet žáka).

Postup (asi 10 minut)

  1. Resend → API Keys → Create API Key. Název Supabase SMTP, oprávnění Sending access, doména matematika-snadno.cz. Klíč (začíná re_) si zkopíruj, Resend ho ukáže jen jednou.
  2. Supabase → Authentication → Emails → SMTP Settings → Enable Custom SMTP (ve starší podobě Supabase je to v Project Settings → Authentication) a vyplň:
    Ulož (Save).
  3. Supabase → Authentication → Rate Limits: „Rate limit for sending emails“ nastav na 60 za hodinu. Bez vlastního SMTP pustí Supabase jen pár e-mailů za hodinu pro celou appku, takže při víc registracích najednou mohla potvrzení čekat nebo nedorazit.
  4. Supabase → Authentication → Emails (Templates) → Confirm signup: do Subject vlož předmět a do Body (Source) celé HTML z první šablony níž. Ulož.
  5. Stejně Reset Password s druhou šablonou. Ulož.
  6. Napiš mi „hotovo“. Ověřím, že vše chodí: nejjednodušší je, když si na matemax.matematika-snadno.cz/zapomenute-heslo pošleš nové heslo na svůj e-mail a řekneš mi, jak vypadá.

Nic se tím nemění na tom, jak registrace funguje, jen odkud a jak e-mail přijde. Kdyby se cokoli pokazilo, stačí v kroku 2 vypnout Custom SMTP a vše se vrátí.

2. Reset Password (zapomenuté heslo)
