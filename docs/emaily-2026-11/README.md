# E-maily MateMaxu (mockup 23. 11. 2026)

- `emaily-samostatne.html` – samostatná stránka (otevři v prohlížeči), obrázky jsou v ní.
- `emaily.html` + `dnes.js` + `img/` – zdroj stránky. `dnes.js` jsou dnešní e-maily vygenerované z kódu appky (týdenní přehled, online testy, uvítání).
- Obrázky Hexíka v `img/` jsou snímky ze 3D modelu appky (pro e-maily, kde 3D nejde).
